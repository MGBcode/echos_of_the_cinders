INSTRUÇÕES DE COMPILAÇÃO E USO

- Linux:
    Instale Raylib e dependências do sistema.
    Exemplo Debian/Ubuntu:
        sudo apt update
        sudo apt install libraylib-dev libgl1-mesa-dev libx11-dev libpthread-stubs0-dev

- Windows:
    Use MSYS2/Mingw ou binários Raylib compatíveis com gcc/MinGW.
    Exemplo MSYS2:
        pacman -S mingw-w64-x86_64-raylib mingw-w64-x86_64-gcc

- Compilar e executar:
    make run

    O alvo `run` compila automaticamente se houver mudanças e executa o binário gerado.

- Controles do jogo:
    - Movimento em 8 direções: W A S D
    - Ataque leve com combos: clique esquerdo
    - Ataque pesado carregável: tecla E
    - Parry: clique direito
    - Cura: tecla Q

DETALHES DE IMPLEMENTAÇÃO

player.c
    - InitPlayer(): inicializa posição, HP, estamina, offsets de hitbox e estados de ataque.
    - UpdatePlayer(): atualiza movimento 8D, dash, controle de parry, lógica de cura e combo de ataques.
    - DrawPlayer(): desenha sprite do jogador, animações e efeitos de hitbox/parry.

enemy.c
    - Boss_Init(): configura HP, fase, timers, AI state machine e parâmetros de ataque do boss.
    - Boss_Update(): processa movimentação do boss, seleção de ataque, colisões e transições de estado.
    - Boss_Draw(): renderiza o boss e seus efeitos visuais.

main.c
    - main(): cria janela Raylib, inicializa subsistemas, executa loop de jogo e finaliza recursos.
    - ciclo principal: leitura de input, UpdatePlayer(), Boss_Update(), detecção de colisões e renderização.

Highlights do Código

Máquina de estados do combo de ataque leve:

    if (attackPressed) {
        if (comboStep == 0) {
            comboStep = 1;
            attackStateTimer = attackWindup[0];
        } else if (comboStep == 1 && comboWindowTimer > 0) {
            comboStep = 2;
            attackStateTimer = attackWindup[1];
        } else if (comboStep == 2 && comboWindowTimer > 0) {
            comboStep = 3;
            attackStateTimer = attackWindup[2];
        }
    }

Fórmula de interpolação do dano pesado:

    float chargeRatio = Clamp(chargeTime / maxChargeTime, 0.0f, 1.0f);
    float damageHeavy = baseHeavy + (maxHeavy - baseHeavy) * chargeRatio;

Dificuldades Encontradas

- Vazamento de estados de dano entre ataques leves/pesados:
    ajustes finos na transição de `attackState` e `comboStep` foram necessários para impedir que um ataque pesado alterasse o fluxo do combo leve.

- Desalinhamento visual do sprite 2.5D top-down em relação à hitbox física e à mira do Boss:
    padronização de offsets de desenho e recalibração da hitbox em `player.pos` resolveram discrepâncias entre o sprite e a lógica de colisão.

- Portabilidade do Makefile para Windows/Linux:
    o Makefile agora usa `ifeq ($(OS),Windows_NT)` para escolher `-lopengl32 -lgdi32 -lwinmm` no Windows e `-lraylib -lGL -lm -lpthread -ldl -lrt -lX11` no Linux.
    comandos de limpeza usam `del /Q` no Windows e `rm -f` no Linux.
